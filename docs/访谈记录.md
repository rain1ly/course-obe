# 访谈记录

> 每一份都原样记录，不润色。这些原话会进技术文档第 1 章和演示视频开场，
> 是「解题有效性」那 25% 的直接证据。

---

## 模板

```markdown
# 访谈记录 0X

- 对象：（学院 / 职称 / 讲授课程）
- 时间：
- 方式：线下 / 电话 / 微信

## 问到的四件事

1. 您这门课要做课程目标达成度评价吗？现在怎么做？
   >

2. 做一次大概花多久？
   >（**这个数字最重要，务必问出来并记录原话**）

3. 哪一步最烦？
   >

4. 督导或评估检查时，最担心什么？
   >

## 拿到的材料

- [ ] 课程大纲（PDF / DOCX，已脱敏）
- [ ] 试卷或作业题目
- [ ] 学生成绩表（Excel，已脱敏）

## 一句话总结
（这个人最想解决的问题是什么）
```
