## 3 架构设计（5 页）

### 3.1 分层与依赖方向
（`pages → core`，core 内部单向。配目录结构图）

### 3.2 数据流
（一次完整请求：上传 → 解析 → 映射 → 确认 → 计算 → 导出。画一条链路图）

### 3.3 模块职责
| 模块 | 职责 | 依赖 |
|---|---|---|
| `core/parsers` | 文件 → 文本 / 表格 | 无 |
| `core/ai_client` | 模型调用与结构化输出 | `core/schemas` |
| `core/domain` | 达成度计算（纯函数） | `core/schemas` |
| `core/db` | 本地持久化 | 无 |
| `pages/*` | 编排与呈现 | 以上全部 |

### 3.4 选型理由
（Streamlit 而非 Next.js 的取舍；SQLite 而非 Postgres 的取舍。见 README「设计取舍」）
